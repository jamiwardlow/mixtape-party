Sticker Pop, dark (#187)

Left to right per direction: Home, Guess, Results. The first row is the shipped light theme for comparison. The hard problem: ink is currently text, border and shadow at once, so on a dark page the shadow vanishes unless it gets its own colour.

Today (light, shipped)

A · Die-cut (recommended)

Page is Ink, cards are a lifted purple, outline and shadow flip to cream. It reads like the white die-cut edge of a real sticker, keeps the 3px / 4px hard-shadow geometry identical, and needs no new rules per component. Accents stay saturated; text on them stays Ink.

C · Die-cut Teal

Same die-cut rules as A, with a near-white outline (#FFFDF5) and a deep version of Mint for the page and cards.

D · Die-cut Deep Blue-Teal

Same rules as C, with the teal pushed toward blue (hue about 200 instead of 180).
